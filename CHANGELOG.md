# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2026-01-01

### Added
- Initial release
- Server-based resource pack profile system
- Automatic pack switching on server join/leave
- F3+A style lightweight reload (no red Mojang screen)
- Full GUI configuration screen
- ModMenu integration
- Keybind support (Right Shift)
- JSON-based configuration
- Default profile support
- 2-second cooldown protection
- Comprehensive logging
- English and German translations

### Features
- Client-side only operation
- Per-server pack profiles
- Enable/disable pack lists
- Exact server address matching
- Thread-safe async operations
- Error handling and validation

### Documentation
- User README
- Technical documentation
- Developer guide
- FAQ
- Quick start guide
- Example configuration

### Safety
- No auto-enable on unknown servers
- Reload loop prevention
- Pack existence validation
- Cooldown mechanism
